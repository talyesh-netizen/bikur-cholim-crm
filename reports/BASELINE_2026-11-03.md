# Reporting baseline before the A1-A9 release (Nov 3, 2026)

Totals only (no names). Worked out by the live site's own funder-export
code (Oct 28, PR #145), run offline on the live entries as they stood on
Nov 3, 2026 (ids and counts only were read; nothing was changed). This is
the counting earlier quarterly reports used; an entry edited since a
report was sent can make a number differ from what was sent. The
"Previous format" export reproduces these numbers line for line. Staff
and volunteer name tables are left out on purpose.
